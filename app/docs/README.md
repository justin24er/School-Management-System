# The School Management App: Project Archive

Start here:
- `app/docs/README-product.md`  what the product is, for customers/users.
- `app/docs/README-internal.md`  architecture, setup, testing, demo accounts,
  security notes, and known limitations, for developers/admins.

Quick start:
```
cd app/backend
cp .env.example .env
npm install
npm run migrate
npm run seed
npm start
```
Then open http://localhost:4000/
